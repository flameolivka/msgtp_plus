# msgtp_plus
Расширение MSGTP+ для внутренних сервисов langame

## Технологии
JavaScript, HTML, CSS. Chromium Extension Manifest V3. Chrome APIs: Storage, Scripting, Permissions. Clipboard API.
Без зависимостей и сборки.

## Установка
Включить режим разработчика на странице расширений Chrome или Edge, выбрать «Загрузить распакованное расширение» и указать папку проекта. Настройки открываются по нажатию на значок расширения.

## Авто. вход на домен
В настройках указать общий логин и пароль и нажать «Сохранить». Сохранённый аккаунт показан логином и зелёным индикатором. «Удалить аккаунт» возвращает форму ввода. Переключатель «Включить / Выключить» управляет всем блоком: при включении форма на /auth.php заполняется и отправляется автоматически, при выключении данные не подставляются.

Мастер-пароля нет. Данные сохраняются локально в IndexedDB расширения: AES-256-GCM, ключ без возможности экспорта хранится в том же профиле браузера. Это не защищает от доступа к самому профилю или компрометации расширения. Прямого доступа к Google Password Manager нет.

Поддерживаются только разрешённые HTTPS-домены и POST-формы с отправкой на тот же сайт. Уже введённый пароль не заменяется; повторный автовход ограничен одной попыткой за 10 минут во вкладке на одном домене. CAPTCHA и второй фактор проходят вручную. Выключение блока и удаление аккаунта не завершают сессии сайтов.
